# BMI Calculator | JavaScript Practice

Educational JavaScript BMI calculator with positive-number validation, result feedback and category styling.

Part of my JavaScript practice work. Explore my complete projects on [GitHub](https://github.com/awaljanhematyar) or my [developer portfolio](https://hematyar-professional-portfolio.vercel.app/).

## Features

- Enter height in centimeters and weight in kilograms.
- Calculate an adult BMI estimate.
- Reject blank, non-finite, zero and negative inputs.
- Announce validation feedback and focus the first invalid field.

## Run locally

```sh
git clone https://github.com/awaljanhematyar/bmi-calculator.git
cd bmi-calculator
```

Serve the folder using VS Code Live Server and open `index.html`. There is no npm installation or build step. Use a modern browser.
